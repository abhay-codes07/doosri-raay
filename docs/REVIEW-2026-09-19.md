# Review findings, 19 Sep 2026 (four independent passes: backend, frontend, infra alignment, judge's eye)

Status legend: **Blocker** = stops deploy or the demo; **High** = judge-visible wrong behaviour; **Medium** = real but unlikely on camera; **Low** = polish. Nothing here is fixed yet.

## Blockers

1. **`make deploy-guided` cannot package the container image.** `Makefile:56-57` passes `--template infra/template.yaml` to `sam deploy`, so SAM uses the source template, finds no `ImageUri` on `RecoveryAgentFunction` and fails; the guided `samconfig.toml` would also be written under `infra/`. Fix: drop `--template` from the deploy targets so SAM uses `.aws-sam/build/template.yaml`.
2. **Recovery pipeline race.** `backend/api/handlers/tasks.py:124-130` calls `SendTaskSuccess` before writing `confirmedTxns`/`ackNo` to the CASE; `Build` (`recovery.asl.json:157-168`) reads the CASE immediately. A warm container can build the 1930 script and narrative with zero transactions and skip MRM. Fix: write the CASE fields before `SendTaskSuccess` (idempotent SET), or pass `$.confirm.txns` in the Build payload.
3. **Stale token tasks stay open.** When a ladder rung or `confirm_fields` times out, the old task is never closed (`ladder.asl.json:132-137`, `backend/ladder/task.py:141-190`); completing it returns 200 but the workflow ignores it, so the ladder still escalates or the case fails. Fix: supersede same-kind open tasks when creating a token task; turn `TaskTimedOut` into `409 task_expired`.
4. **Open-Meteo attribution missing.** `frontend/src/lib/weather.ts:23,44` uses CC BY 4.0 data with no visible credit. Add "मौसम: Open-Meteo.com" under the weather card and a third-party notices line in README.
5. **Demo timers will stop a judge's own case.** Demo mode sets confirm 120 s, 1930 45 s, NCRP 45 s (`backend/common/timeouts.py:156-162`); a judge who reads for two minutes sees "Stopped". Fix: raise demo `confirm` to 900 and the second NCRP attempt to 900, print active timers on the case page, or run a judge stack with `DemoTimeouts=0`.
6. **Location prompt on `/demo` load.** `Parent.tsx:80-83` starts the position watch regardless of permission state; seeded Papa never onboarded, so Chrome prompts on camera. Guard with `geoPermissionState() === 'granted'`.

## High

7. **Onboarding repeats itself.** `App.tsx:123` keys the page on `circleId`; after the pact, `session.reload()` remounts it at the profile step. Drop the key or navigate before reload.
8. **Son's "yes" without a code word tells Papa the call is fake.** `TaskCard.tsx:314` sends an empty code word; backend `_code_word_matched` returns False for empty and for parents with no code word (`tasks.py:83-90`). Disable "yes" until typed; return `null` when no code word is configured.
9. **Manual transaction rows fail server validation.** Client checks UTR only (`CaseDetail.tsx:291`); server requires numeric amount, payee, parseable timestamp. Mirror the rules and use a datetime input.
10. **Service worker never activates new builds while the app is open.** `sw.ts:82-84` has no `skipWaiting()`/`clientsClaim()` in autoUpdate mode. Add both.
11. **`/demo/seed` lets any signed-in user join or overwrite another circle** when enabled (`demo.py:300-335`). Require the caller to already be in the target circle and never upsert profiles that already have a circle.
12. **Check-in cannot stop a ladder in its first seconds, and two watches can coexist.** `activeLadderArn` is written only by rung 1's Lambda (`task.py:193-199`); `start_watch` is read-stop-start without a condition (`checkin.py:61-65`). Pass the execution id into `CheckCheckin` and ignore non-active watches; on rung 1 re-check for a later check-in and resolve.
13. **A midnight check-in kills a live SOS ladder** because `LADDER_KINDS` includes `sos` and the reason is not stored (`checkin.py:107-108`). Store `activeLadderReason`; skip the stop for SOS.
14. **README overreaches.** "No scam vocabulary on the parent screen" (`README.md:87-89`) is false: the Madad buttons say police/CBI/bank and the checker says "यह धोखा हो सकता है". "The app does not work without the pact" (`README.md:305`) is not enforced. Reword or gate.

## Medium

16. Quota weights: one `/cases` can cost 10–15 Sonnet calls; `/uploads` and `/sos` have no quota; self-signup makes quotas per throwaway account. Weight cases by image count; add an upload quota; cap agent iterations.

18. Holiday mode ending or a changed check-in hour never re-arms a Watch (`profile.py:166-170`). Start one from `post_profile` when a parent flips it.
19. `ClassifyWorkerFunction` lacks `UPLOAD_MAX_BYTES` env (`template.yaml:617-628`); diverges if the parameter is overridden.
20. Demo left pane's ID token expires after 60 minutes with no refresh (`Demo.tsx:46-48`). Keep the refresh token or fall back to the sign-in form on 401.
21. Tile left open across IST midnight never re-checks in (`Parent.tsx:43-75`). Add a 60 s day-change tick.
22. Puchho audio `play()` runs outside the tap (`Parent.tsx:308-322`); iOS will block the first play. Unlock a persistent audio element in the click handler.

26. Judge stack: one shared circle and one quota for all judges; "Reset demo" from one judge stops another's ladder. Seed two or three judge circles and raise `DailyQuota` there.
